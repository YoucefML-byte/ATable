# Atable

Plateforme **multi-commerces** de commande à table par QR code ou puce NFC (restaurants, bars, chichas,
cafés…). Un seul code et une seule base servent tous les commerces ; chaque commerce a son domaine,
son thème et ses données isolées. Le client commande sans compte, l'équipe valide chaque commande,
la cuisine prépare, le paiement se fait au comptoir (aucun paiement en ligne).

« Atable » est un nom de travail.

Le code de l'application est développé sur des branches et fusionné par pull request.
